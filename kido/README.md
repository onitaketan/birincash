# 鬼道占術 — 縁鍛冶 (Relation Forge)

生年月日から「本命鬼」を導き、二人の「縁の型」を鑑定する和風占術ウェブアプリです。
`index.html` 一枚で動く静的アプリで、ビルド手順も外部 JavaScript ライブラリもありません。

## 機能

| 画面 | 内容 |
|---|---|
| 鬼命鑑定 | 生年月日（＋任意で時刻）から四柱を組み、日柱の十二支に対応する本命鬼・そなわる力・陥りやすい癖・五行の偏り・守りの一覧・今日の気配を表示します。 |
| 縁の鍛冶 | 二人の日柱を突き合わせ、三合／支合／対冲／比和／相刑／相害／相破／淡交のいずれの縁かを判定し、縁の濃さ・起きやすいこと・縁を鍛える三箇条を出します。恋愛・仕事・友愛・家族で読み分けます。 |
| 鑑定の記録 | 鑑定した人を端末内（localStorage）に保存し、呼び出し・相性鑑定への引き渡し・削除ができます。サーバーへは送信しません。 |

結果はテキストとしてクリップボードへ写せます。

## 占術ロジック

- **日柱** — ユリウス通日から六十干支を算出（`(JDN + 49) mod 60`）。1900-01-01＝甲戌、2000-01-01＝戊午の二点で検証済み。
- **年柱** — 立春をもって改まります。
- **月柱** — 節入り（小寒・立春・啓蟄…）で切り替え、月干は年干から導出（甲己之年丙作首）。日付は近似値を用いています。
- **時柱** — 早子時法。時干は日干から導出（甲己還加甲）。
- **本命鬼** — 日柱の十二支に対応する十二鬼。
- **縁の型** — 十二支の三合・支合・対冲・相刑・相害・相破に、日干の五行（相生・相剋・比和）と陰陽を加味して算出。

144 通りすべての十二支の組み合わせが、いずれかの縁の型に対称に割り当てられることを確認しています。

## 動かす

```sh
# そのまま開く
open kido/index.html

# もしくはローカルサーバーで
npx serve .
```

## Vercel へ置く

このリポジトリのルートには別のアプリ（仮払金出納帳）があるため、本アプリは `kido/` 以下に置いています。

- リポジトリ全体を配信する場合 — `/kido/` で開きます。
- 本アプリ単体のプロジェクトにする場合 — Vercel の **Root Directory** に `kido` を指定してください。フレームワークは "Other"（静的配信）で、ビルドコマンドは不要です。
